# Soul Knife Tanks

Мультиплеерный 2D-шутер на танках. Два игрока подключаются и сражаются на одной карте: подбирают оружие, уворачиваются от снарядов и стараются уничтожить противника первыми!

---

## Требования

- **C++20** — стандарт сборки
- **CMake** ≥ 3.16
- **SFML** 2.5

```bash
sudo apt install libsfml-dev cmake g++
```

---

## Сборка и запуск

```bash
git clone <repo-url>
cd MULTIPLAYER_ACTION_SHUTER_TANKS_2.0_hahaha

mkdir build && cd build
cmake ..
make

./project
```

## Как играть

### Меню

| Действие | Клавиша |
|----------|---------|
| Выбрать скин | `A` / `D` или `←` / `→` |
| Подтвердить | `Enter` / `Space` |

### Создание / подключение к лобби

| Действие | Клавиша |
|----------|---------|
| Создать лобби (хост) | `1` |
| Присоединиться | `2` |
| Назад | `Escape` |

После создания лобби хосту показывается **4-буквенный код** — передай его другому игроку. Гость вводит код и нажимает `Enter`.

### Игра

| Действие | Клавиша |
|----------|---------|
| Движение | `W A S D` |
| Выстрел | `ЛКМ` или `Space` |

- Подъедь к тайлу с оружием, чтобы подобрать его
- Овцы наносят урон, лужи замедляют
- Побеждает тот, кто первым уничтожит противника

## Оружие

| Оружие | Снаряды | Механика |
|--------|---------|----------|
| Пушка (Gun) | ∞ | Стандартный одиночный выстрел |
| Дробовик (Shotgun) | 5 залпов | Веер из 5 пуль |
| Рикошетная пушка (Ricochet Gun) | 5 залпов | Снаряды отражаются от стен |

При израсходовании патронов оружие автоматически заменяется на стандартную пушку.

```
├── Entity.hpp              # Базовый класс сущности
├── Player.hpp

```
